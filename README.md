# Code for "Auditing the Predictive Ceiling of a Fitted Representation: Case Studies in
# Air-Shower Reconstruction"

Anonymised for review. Every number, table and figure in the manuscript is generated by
`run_pipeline.py` from `analysis/results.json`; nothing is typed by hand.

    pip install -r requirements.txt
    python run_pipeline.py --check     # data integrity and event counts
    python run_pipeline.py --full      # recompute every result from the data (~30 min, 32 cores)

## Data

* GRAPES-3 simulation (`data/feature_24.6_5.0.root`, `data/feature_24.6_4.8.root`) and the
  archived prediction table (`data/grapes3_ml_results.csv`): released on Zenodo with the
  collaboration's permission (DOI in the published paper). Place the three files in `data/`;
  `run_pipeline.py --check` verifies them against `SHA256SUMS.txt`.
* KASCADE simulation: public from the KASCADE Cosmic-ray Data Centre, https://kcdc.iap.kit.edu/
  (Simulations > QGSjet-II-04 > KASCADE, "download All"). Unzip into `data/kcdc/` and run
  `python analysis/kcdc/convert_kcdc.py` and `python analysis/kcdc/extract_stations.py`.
  `analysis/kcdc/kascade_station_coordinates.csv` is Appendix A of the KCDC Simulation Manual
  (V.02.3); `check_station_mapping.py` validates it against the data.

`analysis/results.json` and `analysis/kcdc/kcdc_results.json` hold every aggregate number the
manuscript reports, so each claim can be checked against them without the data. Regenerating
the results, tables and figures requires the data (the pipeline checks its hashes and event
counts first and stops if they are absent).

## What each added analysis is

* `analysis/run_synthetic.py`: the known-truth benchmark (no external data needed; runs alone).
* `analysis/run_tmlr_checks.py`: floor estimates with the evaluation events as query points,
  shower-level intervals, and the two units of the KASCADE gap fractions.
* `analysis/run_shower_crossfit.py`: the shower-disjoint cross-fit of the estimator table, the
  ladder, the selection sweep and (from fold runs) the networks on rendered input.
* `analysis/run_render_seeds.py`: further training seeds for the networks on rendered input.
  `RENDER_FOLD=<k> python analysis/run_rendering.py` produces one cross-fit fold.
* `analysis/kcdc/run_kcdc_floor_sens.py`: sensitivity of the KASCADE floor estimate.
* `analysis/make_tables_tmlr.py`: the tables and macros specific to this manuscript.

## Order

`run_all.py` rewrites `results.json`; every other `run_*.py` extends it. `make_tables.py` writes
`tables/values.tex`; the other `make_tables_*.py` append. `run_pipeline.py` encodes the order.
`analysis/verify_numbers.py` checks every number in the manuscript prose against the results.
